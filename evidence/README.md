# Evidence

Raw proof from real lab runs: redacted command output, screenshots, alert emails and timings.

Rules:
- Every file comes from a real run and is dated.
- Subscription and tenant IDs, emails, IP addresses and tenant names are redacted.
- Nothing here is edited to look better than it was.

Layout: `evidence/<lab-or-drill>/<YYYY-MM-DD>-<what>.<ext>`
